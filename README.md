### Problem Statement

Develop a C++ program using Object-Oriented Programming (OOP) to perform bidirectional time conversions:
1. Convert total seconds into **Hours, Minutes, and Seconds (HH:MM:SS)** format.
2. Convert **Hours, Minutes, and Seconds (HH:MM:SS)** into **Total Seconds**.

### Concept Used

* C++ Object-Oriented Programming (Classes and Objects)
* Member functions (`convertTohour`, `convertToSeconds`)
* Arithmetic operations (Division `/` and Modulus `%`)
* Menu-driven interface using `switch-case`
* Standard I/O operations (`cin`, `cout`)
